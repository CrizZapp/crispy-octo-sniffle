ALLEN API PRO

AllenApi_System

Bienvenido al panel central de control. Esta API simula respuestas automáticas con estructuras JSON validadas para el desarrollo y testeo de integraciones externas en tiempo récord.

MÉTODO_DE_PETICIÓN

Puedes realizar llamadas directamente usando el endpoint en la URL. Los bots obtendrán un objeto JSON limpio y parseable.

fetch("https://tu-dominio.com/kiss")
  .then(res => res.json())
  .then(data => {
    console.log(data.action); // "kiss"
    console.log(data.gif);    // URL del archivo gif
  });
