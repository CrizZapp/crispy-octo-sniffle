AllenApi_System

API optimizada para funcionar 100% en entornos estáticos como GitHub Pages sin errores 404.

PETICIÓN_HTTP (Bots)

En GitHub Pages debes pasar la variable ?api= al final de tu enlace para no generar un 404.

// Ejemplo para tu bot:
fetch("https://tu-usuario.github.io/tu-repo/?api=kiss")
  .then(res => res.json())
  .then(data => {
    console.log(data.action); // "kiss"
    console.log(data.gif);    
  });
