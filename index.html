Bienvenido a AllenApi 👑

La API definitiva para obtener reacciones de anime al instante. Diseñada con un motor de enrutamiento estático, responde en milisegundos entregando JSON puro para tus bots de Discord, Telegram o páginas web.

📖 Cómo hacer peticiones (Fetch)

Al ser una API basada en Hash de URL, para obtener los datos desde tu código solo debes agregar el nombre del endpoint con un # al final de la URL del archivo.

Ejemplo en JavaScript:

// 1. Apunta a la URL de tu archivo y añade el endpoint (ej: #kiss)
const apiUrl = "tu_pagina.html#kiss";

// 2. Haz la petición fetch
fetch(apiUrl)
  .then(response => response.text()) // Leer como texto/html
  .then(html => {
    // 3. Extraer el JSON puro del body
    const parser = new DOMParser();
    const doc = parser.parseFromString(html, "text/html");
    const jsonPuro = JSON.parse(doc.body.innerText);
    
    console.log(jsonPuro.gif); // Muestra el link del GIF!
  });
